# Hotel Podgore — посадкова сторінка подій

## Запуск
Відкрийте `index.html` у браузері.

## Адмін-панель
Відкрийте `admin.html`.
Стартовий пароль: `podgore-admin`.

У прототипі зміни зберігаються у LocalStorage браузера. Можна редагувати ціни, пакети, послуги, назви подій, завантажувати головне фото та до 6 фото галереї, переглядати заявки.

Для роботи з різних пристроїв та реального запуску потрібне підключення Supabase/іншої бази даних, захищеної авторизації та каналу надсилання заявок.
