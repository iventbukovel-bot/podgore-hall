# Podgore Hall

Статичний люксовий лендинг для Vercel.

## Адмін-панель
Відкрийте `/#admin` або натисніть «Вхід в адмін-кабінет» у футері.

Стартовий пароль: `podgore-admin`

> Поточна адмінка працює через localStorage і зберігає зміни лише в браузері конкретного пристрою. Для спільного онлайн-керування потрібна база даних (наприклад Supabase).
